# 안녕하세요, Flutter 개발자 박찬섭입니다 👋

디바이스와 앱을 안정적으로 잇는 일에 관심이 많습니다. Flutter를 화면 너머 **네이티브 연동·플러그인·출시·운영**까지 다루고, **AI 도구로 개발과 QA를 자동화**합니다.

- 🔩 네이티브 연동: MethodChannel, 외부 디바이스 SDK(.aar) 플러그인화, BLE
- 📦 Flutter 플러그인 개발·pub.dev 배포
- 🧪 앱 단독 출시·운영, Crashlytics 기반 품질 안정화, 자체 QA 자동화
- 🤖 Claude Code 스킬 제작 등 AI 기반 개발 워크플로
